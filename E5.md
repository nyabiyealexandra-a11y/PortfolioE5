## Other requirements of the guide

| Requirement                                                  | How the site meets it                                                                                    |
| ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| Clear organisation, a menu to reach each section directly    | One page with a numbered navigation bar, in the order suggested by the guide                             |
| For each project: context, goal, technologies, role, results | Enforced by the `Project` type in `projets.ts`: a project without results does not compile               |
| Show the process, not only the result                        | `documents` field of each project, `figure` blocks for diagrams and screenshots                          |
| Link each skill to a project or situation                    | Each skill card links to a project/mission card (`#projet-…`, `#mission-…`); the build checks every link |
| 10 to 15 watch articles                                      | Checked by `tests/site.test.ts`                                                                          |
| Online and accessible to the jury                            | Deployed to GitHub Pages on every push to `main`: <https://nyabiyealexandra-a11y.github.io/PortfolioE5/> |
| Every link, document and image works                         | The build fails on a broken internal link or a missing file in `public/`                                 |
| No confidential company information                          | Rules in [CONTRIBUTING.md § 11](CONTRIBUTING.md#11-rules-for-the-content)                                |
